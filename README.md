# Many Faces Online previews

Review previews of the nine Many Faces Online sites (Beauty, Robotics, Sauna, Golf, Watch Collector, Espresso, Home Gym, Game Room, Smart Telescopes), built from each site's Shopify theme. These are not the live stores: no checkout, no live prices or commissions. Pages are marked noindex and robots.txt disallows crawling.

Rebuilt by Claude from each site repo's `main` branch.

`control-center/` is a separate preview of the Control Center app (POCIT LLC), with sample data only and read-only. It is not linked from the Many Faces page.
